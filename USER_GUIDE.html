Prophylactic Pelvic Nodal Irradiation – NNT Comparator: User guide

Quick start

  1. Open index.html.
  2. Select Definitive RT · POP-RT or Salvage RT · SPPORT.
  3. Read the published outcome, absolute benefit and exact NNT. The bracketed line shows the subtraction used.
  4. Review the toxicity, QOL and 100-patient trade-off information from the same trial.

Using your own parameters

  1. Select whether your percentages describe an event-free outcome/survival or an adverse-event rate.
  2. Enter comparator and treatment percentages measured at the same timepoint using the same endpoint definition.
  3. The tool reports NNT for benefit or NNH for harm, the absolute difference and conventional whole-patient rounding.
Example: event-free outcome rises from 81.2% to 95.0%. Absolute benefit = 95.0 − 81.2 = 13.8 percentage points. Exact NNT = 1/0.138 = 7.25; conventional whole-patient NNT = 8.

Clinical trade-off tables

The POP-RT table summarizes whole-pelvic rather than prostate-only RT per 100 comparable definitive-treatment patients. The SPPORT table separates adding short-term ADT, subsequently adding pelvic-node RT, and using the full strategy versus PBRT alone. On a phone, swipe the SPPORT table horizontally to view all columns. Categories such as biochemical failure, FFP, metastasis and toxicity overlap and must not be added together.

Advanced interpretation

NNT is baseline-risk and timepoint dependent. Do not transfer a trial NNT to patients whose prognosis, imaging, systemic therapy, radiation technique or follow-up differs materially. A hazard ratio is not interchangeable with a risk ratio or NNT. When a difference is statistically non-significant, any displayed reciprocal is descriptive rather than confirmatory.

Offline use

Directly opening index.html works without internet access. For installable app behaviour and automatic caching, serve the complete folder over HTTPS and choose “Install app” or “Add to Home Screen”. Keep all files and the icons folder together.
